# TrendQuiz Frontend (Expo)

This is a minimal scaffold for the Expo app used by TrendQuiz. It includes basic screens and a simple API + WebSocket helper.

Quick start:

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Start Expo:

```bash
npm start
# or
npx expo start
```

3. Open in Expo Go on your device or in a simulator.

Notes:
- The app expects the backend at `http://127.0.0.1:8000`. When running on a device, change `API_BASE` in `src/api/client.js` to your machine's IP or use ngrok.
- This scaffold is minimal — replace simple global token storage with secure storage for production.
